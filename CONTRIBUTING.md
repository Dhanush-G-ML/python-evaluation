# Pull request rules

Use one branch and one pull request per topic. Choose any valid Git branch name and keep your changes under `submissions/<your-folder>/<topic-folder>/`.

1. Update `main` before starting a topic, then create your submission branch.
2. Write the assigned exercises in your folder. You may refer to the shared exercises and other submissions. Keep your PR limited to your own topic folder.
3. Run your work against the examples. In the PR template, list the exercise IDs, commands you ran, results, and any help you used.
4. Open the PR with `main` as the base and request your mentor's review. Read the **Submission checks** result under **Checks**. It checks that the PR changes one submission topic folder and verifies Python syntax.
5. Make requested changes on the same branch. Respond to the review comments, then wait for your mentor to merge.

The [submission guide](README.md#submit-your-work) provides the Git commands and explains how to open your PR.
